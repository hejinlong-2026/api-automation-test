# 测试用例清单（MiniShop 电商接口）

> 设计方法：等价类划分 / 边界值分析 / 场景法 / 错误推测 / 状态迁移
> 优先级：P0 主流程与资损相关；P1 主要功能；P2 异常与体验

## 一、用例总览

| 登录 | 13 | 13 | 0 |
| 商品查询 | 9 | 9 | 1（D-001） |
| 购物车 | 10 | 10 | 1（D-002） |
| 订单 | 11 | 11 | 1（D-003） |

## 五、订单模块（状态机 + 越权 + 金额）

| 编号 | 用例标题 | 步骤 | 预期结果 | 优先级 |
|---|---|---|---|---|
| ORDER-01 | 单品下单 | P001 × 3 | amount = 0.03（无浮点溢出） | P0 |
| ORDER-02 | 多品下单 | P001×2 + P002×1 | amount = 1299.02 | P0 |
| ORDER-03 | 支付后状态一致 | 下单 → 支付 → 查询 | 状态 CREATED → PAID 一致 | P0 |

| ORDER-05 | B 查 A 的订单 | B 的 token 查 A 单号 | 404 | P0 |
| ORDER-06 | B 支付 A 的订单 | B 的 token 支付 | 404 | P0 |
| ORDER-07 | 库存为 0 下单 | P003 × 1 | 400 库存不足 | P1 |
| ORDER-08 | 购买量 = 库存 / 库存+1 | P002 | +1 失败，=库存 成功 | P1 |
| ORDER-09 | 负数数量下单 | P001 × -5 | 400（否则可反向加库存） | P0 |
| ORDER-10 | 空商品列表 | items=[] | 400 | P1 |
| ORDER-11 | 下单不存在商品 | NOT_EXIST | 404 | P1 |
